1. Support logging in with STS credentials that only have permission on a single object: the preset path is no longer forced to be treated as a directory. When listing is not allowed, the client falls back to HeadObject validation and opens that object directly. The issued policy prefix condition now also supports object paths.
2. AK histories are now displayed in a dialog, with search, secret show/hide, use, delete and clear history supported. The dialog shows the description, region, endpoint and preset OSS path of each AK history.
3. Add a GitHub Actions multi-platform release workflow: pushing a v* tag builds Windows x64/ia32, Linux x64/ia32 and macOS (optional) artifacts and publishes a Release.
4. Improve the release pipeline: install yarn inside the project to avoid Windows global installation failures, mark the macOS build as optional so it does not block other platforms, and always run the release job even if an optional platform is cancelled.
5. Document the upstream fork in README and add release notes for this version.
