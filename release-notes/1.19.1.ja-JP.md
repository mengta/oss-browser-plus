1. 単一オブジェクトの権限のみを持つ STS 一時認証情報でのログインをサポートしました。プリセットパスをディレクトリとしてのみ扱うことをやめ、リスト取得権限がない場合は HeadObject による検証にフォールバックして該当オブジェクトを直接表示します。発行ポリシーの Prefix 条件はオブジェクトパスにも対応しました。
2. AK 履歴をクリックするとダイアログで表示するように変更しました。検索、AccessKeySecret の表示/非表示、使用、削除、履歴のクリアに対応し、各履歴の説明、リージョン、Endpoint、プリセット OSS パスを表示します。
3. GitHub Actions によるマルチプラットフォームのリリースビルドワークフローを追加しました。v* タグをプッシュすると Windows x64/ia32、Linux x64/ia32、macOS（オプション）の成果物をビルドし、Release を公開します。
4. リリース処理を改善しました。yarn をプロジェクト内にインストールして Windows でのグローバルインストール失敗を回避し、macOS ビルドをオプション扱いにして他のプラットフォームの公開をブロックしないようにし、オプションのプラットフォームがキャンセルされてもリリースジョブを必ず実行するようにしました。
5. README にアップストリームプロジェクトからの fork であることを記載し、今回のバージョンのリリースノートを追加しました。
