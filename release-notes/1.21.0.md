# OSS Browser Plus 1.21.0

## 架构变化

- 渲染层由 AngularJS 1.8 整体迁移至 **Vue 3 + Pinia + Vue Router**：登录、文件页（Bucket/对象浏览/搜索/排序/分页）、上传/下载与传输中心、文件操作弹窗、四类预览与 flv 播放、右键菜单、设置/关于/收藏/用户/AK、简化 Policy 与授权码全部由 Vue 承载。
- 渲染世界无 Node、无原始 IPC：OSS/STS/RAM/邮件/传输/升级等能力经 `contextBridge` 白名单由主进程/preload 承载（`sandbox=false`，见下）。
- 构建：Vue bundle 输出 `dist/app.js`；AngularJS 运行时与模板缓存移除；CodeMirror 6 取代 CM5；dayjs 取代 moment；图标以内联 SVG 取代 Font Awesome 4；二维码由 `qrcode-generator` 生成矩阵 + 自研 SVG 渲染（移除 `jquery.qrcode`）。
- 安全：凭证沿用 `safeStorage` 信封加密（v2）/ 降级 v2d；断点续传进度文件由旧明文命名自动迁移为 sha256 前 16 位脱敏命名（先写后删等价，失败保留旧文件）。

## 已知差异

- 渲染进程 `sandbox=false`：`safeStorage`、`ali-oss`、`nodemailer` 等 CommonJS 依赖无法在 sandbox 渲染进程加载；渲染世界由 `contextIsolation` + 白名单保护（无 Node、无任意路径、无原始 IPC）。
- 入口页 CSP 收敛为 `script-src 'self'`（移除内联脚本与 hash 白名单）。
- 邮件分享中的二维码为 SVG data URL（原为 canvas JPEG），内容/尺寸一致。
- 旧版 Angular 页面路由不再提供；`#/login` 与默认 hash 均由 Vue 路由处理。
- 语言包沿用 `node/i18n/*.js` 单一来源，构建期把 Angular `{{name}}` 插值转换为 vue-i18n `{name}`。

## 升级说明

- 版本号 1.21.0；关于页「检查更新 → 下载 → 安装并重启」流程与原版一致（清单不可达静默，不阻塞主功能）。
- 断点续传进度在首次启动时自动迁移，无需手工操作。
