# OSS Browser Plus 1.21.1

## 主要变化

- **渲染层整体重写为 Vue 3 + Pinia + Vue Router**：登录、文件页、文件操作弹窗、四类预览与 flv、传输中心、设置/关于/收藏/用户/AK、简化 Policy 与授权码全部迁至 Vue；AngularJS 运行时移除。
- **VS Code Dark+/Light+ 界面**：35px 标题栏、44px 活动栏、`#007acc` 状态栏、命令面板（Ctrl+Shift+P）、面包屑地址栏、深/浅/跟随系统主题、CM6 深色编辑器。
- **安全**：渲染层无 Node、无原始 IPC；OSS/STS/RAM/邮件/传输/升级经 `contextBridge` 白名单由主进程承载；凭证沿用 safeStorage 信封加密。

## 问题修复

- 请求者付费模式：恢复上传/下载链路的 `x-oss-request-payer` 传递、AK 历史标签与文档链接；登录页移到「记住密钥」同排并放最后。
- 登录页「?」帮助浮窗改为自研 HintTooltip（Electron 下原生 title 不弹出）。
- 地址栏补「刷新 / 主页 / 保存为首页」；设置补「保存历史记录长度」；临时凭证显示 `HH:mm:ss` 倒计时（validUntil 浮窗）。
- 关于页仅保留开源地址 `https://github.com/mengta/oss-browser-plus`（移除版本检测/uptodate 展示）。
- 渲染层构建依赖移出生产依赖：asar 38.4MB → 20.1MB，win32 zip 150.6MB → 146.8MB。

## 已知差异

- 渲染进程 `sandbox=false`（safeStorage/ali-oss 等 CommonJS 依赖），由 `contextIsolation` + 白名单保护。
- 旧 Angular 路由不再提供；分享邮件中的二维码为 SVG data URL。
