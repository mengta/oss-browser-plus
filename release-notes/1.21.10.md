# OSS Browser Plus 1.21.10

## 重点修复

- **登录与凭证**：改为左右分栏登录页（品牌区 + 表单卡片，AK/授权码切换语义化 tab）；修复「获取地址」探测的两处问题（`invalid url`、`app:probe-url failed`），探测不可达时降级为签名链接；配置导入不再被无效剪贴板内容覆盖；AK 历史按钮与表单在深色下对比度达标。
- **列表与收藏**：收藏按钮随当前目录正确高亮（预热 + 尾斜杠规范化）；块视图补齐图片缩略图（按需 `image/resize` 签名）与存储类型/时间信息；列表更紧凑并新增存储类型列，视图切换改用 list/grid 图标与 `aria-pressed` 语义；移除地址栏中意义不明的「保存为首页」。
- **传输与退出**：登出时停止后台上传/下载并清空按账号隔离的收藏与列表缓存；修复拖拽上传路径解析、视图订阅 ID 的异步信封退订；升级安装失败不再被静默当作成功。
- **主题与层级**：统一 dark/light 灰底控件文字（`color-scheme`、按钮/选项/复选框自绘），新增三档表面色（列表/工具栏、导航/卡片、表头），列表与登录页视觉层级更清晰。

## 工程与测试

- ava **90** + Vitest **606/606（68 files）**；覆盖率 statements 84.05%、lines 86.05%、branches 73.12%、functions 77.42%（门槛 82/84/70/75）。
- E2E **28 用例：21 passed / 7 skipped**（无凭证按设计跳过）；新增 smoke-13（安全基线）、smoke-14（窗口与主题）、smoke-15（登录页分栏与 tab 语义）。
- 新增 preload 11 个能力域的单元测试；修复 Playwright 在宿主环境下的 `ELECTRON_RUN_AS_NODE` 污染（独立 user-data-dir + 显式覆盖）。
- 依赖更新：`@codemirror/*` 小版本升级、新增 `@vitest/coverage-v8`、`fake-indexeddb`。

## 兼容性

- 与 1.21.9 的配置、AK 历史、书签（收藏）数据保持兼容；登录地址的尾斜杠差异不再影响收藏判定。
