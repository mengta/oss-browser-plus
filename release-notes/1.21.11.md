# OSS Browser Plus 1.21.11

## 发布修复（相对 1.21.10）

- **CI 跨平台**：crc64 裁剪单测改为按构建目标平台（linux-x64 / darwin-x64 / win32-x64）动态断言，修复 Linux job 的 ava 失败。
- **行数门禁**：登录页拆分出 `LoginBrandPanel` / `LoginModeTabs`，文件页测试拆分为 `files-page` / `files-page-actions` / `files-page-bucket`；豁免清单按本批次实际增长更新，PR Gate 恢复通过。

## 内容（与 1.21.10 一致）

- **登录与凭证**：左右分栏登录页（品牌区 + 表单卡片，AK/授权码语义化 tab）；修复「获取地址」的 `invalid url` 与 `app:probe-url failed`，探测不可达时降级为签名链接；配置导入不再被无效剪贴板内容覆盖；AK 历史按钮与表单深色对比度达标。
- **列表与收藏**：收藏按钮随当前目录正确高亮（预热 + 尾斜杠规范化）；块视图补齐缩略图与存储类型/时间；列表更紧凑并新增存储类型列，视图切换改用 list/grid 图标与 `aria-pressed`；移除地址栏「保存为首页」。
- **传输与退出**：登出停止后台上传/下载并清空按账号隔离状态；修复拖拽上传路径、订阅异步信封退订、升级安装失败被静默当作成功。
- **主题与层级**：统一 dark/light 灰底控件文字（`color-scheme`、按钮/选项/复选框自绘），新增三档表面色，列表与登录页层级更清晰。

## 工程与测试

- ava **90** + Vitest **606/606（70 files）**；覆盖率 statements 84.05%、lines 86.05%、branches 73.12%、functions 77.47%。
- E2E **28 用例：21 passed / 7 skipped**（无凭证按设计跳过）；新增 smoke-13/14/15。
- preload 11 个能力域单测；修复 Playwright 在宿主环境下的 `ELECTRON_RUN_AS_NODE` 污染。

## 兼容性

- 与 1.21.9 的配置、AK 历史、书签数据兼容；收藏判定不再受体裁尾斜杠差异影响。
