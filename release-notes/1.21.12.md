# OSS Browser Plus 1.21.12

## 发布修复（相对 1.21.10/1.21.11）

- **CI 跨平台**：crc64 裁剪单测的目标平台改为从 `dist` 内实际裁剪结果推断（macOS runner 的架构可能与 matrix arch 不同），并在未构建时回退当前平台；三平台 ava 门禁恢复。
- **PR Gate**：列表性能门禁前安装 Playwright Chromium（`--with-deps chromium`），修复无浏览器环境下 exit 2。
- **行数门禁**：登录页拆分 `LoginBrandPanel` / `LoginModeTabs`，文件页测试拆分为三个文件；豁免清单按实际增长更新。

## 内容（与 1.21.10 一致）

- **登录与凭证**：左右分栏登录页；修复「获取地址」的 `invalid url` / `app:probe-url failed`（探测不可达降级签名链接）；配置导入不再被无效剪贴板覆盖；AK 历史深色对比度达标。
- **列表与收藏**：收藏高亮（预热 + 尾斜杠规范化）；块视图缩略图与存储/时间信息；列表新增存储类型列、list/grid 视图图标与 `aria-pressed`；移除「保存为首页」。
- **传输与退出**：登出停止后台传输并清空账号级状态；拖拽路径、订阅异步信封退订、升级失败识别。
- **主题与层级**：统一 dark/light 灰底控件文字，新增三档表面色。

## 工程与测试

- ava **90** + Vitest **606/606（70 files）**；E2E **28 用例：21 passed / 7 skipped**。
- 覆盖率 statements 84.05%、lines 86.05%、branches 73.12%、functions 77.47%。

## 兼容性

- 与 1.21.9 的配置、AK 历史、书签数据兼容。
