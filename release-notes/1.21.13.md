# OSS Browser Plus 1.21.13

## 发布修复（相对 1.21.12）

- **体积门禁跨平台**：`gate-size` 的“三核心”检查不再只认 `oss-browser.exe`，同时接受 Linux 的 `oss-browser` 与 macOS 的 `oss-browser.app/`；CI 体积门禁失败时注入 `::error` 摘要便于自助诊断。
- 其余发布链路修复同 1.21.12（crc64 目标平台从 dist 推断、PR Gate 安装 Chromium、行数门禁拆分）。

## 内容（与 1.21.10 一致）

- **登录与凭证**：左右分栏登录页；获取地址 `invalid url` / `app:probe-url failed` 修复；配置导入剪贴板覆盖修复；AK 历史深色对比度。
- **列表与收藏**：收藏高亮（预热 + 尾斜杠规范化）；块视图缩略图/存储/时间；存储类型列、list/grid 图标与 `aria-pressed`；移除「保存为首页」。
- **传输与退出**：登出停止后台传输并清空账号级状态；拖拽路径、订阅异步信封退订、升级失败识别。
- **主题与层级**：统一 dark/light 灰底控件文字，新增三档表面色。

## 工程与测试

- ava **90** + Vitest **606/606（70 files）**；E2E **28 用例：21 passed / 7 skipped**。
- 覆盖率 statements 84.05%、lines 86.05%、branches 73.12%、functions 77.47%。

## 兼容性

- 与 1.21.9 的配置、AK 历史、书签数据兼容。
