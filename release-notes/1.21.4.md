# OSS Browser Plus 1.21.4

## 变更

- 与 1.21.3 功能内容一致（Vue 3 重写 + VS Code Dark+/Light+ 界面、请求者付费链路修复、帮助浮窗、地址栏主页/刷新、设置历史长度、关于页开源地址）。
- 修复发布流水线：Windows 本地生成的 `package-lock.json` 缺少跨平台 optional 依赖（`@emnapi/core`、`@emnapi/runtime`），导致 CI（Linux/macOS/Windows）`npm ci` 报 EUSAGE。CI 在 `npm ci` 前按当前平台执行 `npm install --package-lock-only` 补齐 lock，再严格安装。
- v1.21.1 / v1.21.2 / v1.21.3 tag 保留审计。
