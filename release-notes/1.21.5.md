# OSS Browser Plus 1.21.5

## 修复

- **登录故障**：修复真实 AK/SK 登录报 `auth.accessKeyId is required`。主进程认证入口统一归一化渲染层凭证字段（`id/secret/stoken` → `accessKeyId/accessKeySecret/securityToken`），覆盖 oss/ram/sts 与传输链路；此问题影响 1.21.4 及更早的 Vue 版本。
- **移除自动更新**：设置页删除「自动更新」项，移除启动自动检测、顶栏 `new` 角标与 `upgradeService`（主进程升级能力保留，渲染层无调用）。
- **导航栏精简**：删除顶栏语言切换选框（语言切换保留在设置页）。

## 说明

- 与 1.21.4 的 Vue 3 重写 / VS Code Dark+·Light+ 界面一致。
- 发布流水线沿用 1.21.4 的平台内 `npm install --package-lock-only` 修复（跨平台 optional lock 同步）。
