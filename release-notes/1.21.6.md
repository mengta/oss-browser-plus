# OSS Browser Plus 1.21.6

## 变更

- 产品内容与 1.21.5 一致：登录认证字段归一化（修复 `auth.accessKeyId is required`）、移除自动更新、移除导航栏语言选框。
- 发布流水线：v1.21.5 的 Windows job 在 E2E 步骤失败（导致 Release 缺少 win32-x64.zip）；本版为 Windows E2E 增加**一次自动重试**（冷启动抖动）与失败摘要注入（Actions annotation，匿名可读），确保 win32 产物可发布。
- v1.21.5 Release 仅含 linux/mac 资产，请使用 1.21.6。
