# OSS Browser Plus 1.21.7

## 修复

- **凭证惰性迁移回归**：1.21.5/1.21.6 移除自动更新时误删了 App 启动时的 `useSettingsStore()` 初始化，导致 `mailSender`（SMTP）旧格式凭证的惰性迁移不再触发（smoke-10 断言失败、Windows 产物未发布）。本版恢复启动时 settings 初始化（仅迁移/读取配置，**不做自动更新**）。
- Windows E2E 一次重试与失败摘要注入保留。

## 内容

- 与 1.21.5/1.21.6 一致：登录认证字段归一化（修复 `auth.accessKeyId is required`）、移除自动更新设置与逻辑、移除导航栏语言选框（语言切换在设置页）。

## 说明

- v1.21.5 / v1.21.6 Release 缺少 win32-x64.zip（Windows job E2E 失败），请使用 1.21.7。
