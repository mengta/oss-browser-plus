# OSS Browser Plus 2.0.0

本次更新围绕日常使用体验做了集中改进。

## 登录与账号

- 支持只有某个 Bucket 或某个目录权限的账号登录，不再要求能列出全部 Bucket。
- 支持 AK 只能访问单个文件的场景：在「预设 OSS 路径」填写完整文件地址（如 `oss://bucket/目录/文件.txt`），登录后会直接显示该文件。
- 修复部分环境下提示「endpoint 格式」错误、获取地址失败的问题。
- 配置导入更可靠，不再被剪贴板中的无关内容干扰。

## 文件列表

- 收藏按钮会正确显示当前目录是否已收藏。
- 新增「存储类型」列，列表与块视图的切换图标更直观。
- 上传完成后当前目录会自动刷新，无需手动刷新。
- 列表更紧凑，深色模式下各区域层次更清晰。

## 文件操作

- 修复删除文件时弹窗卡住无响应的问题；删除成功或失败原因都会明确展示。
- 获取下载/分享地址更稳定。

## 提示与界面

- 登录失败提示会保留 60 秒，支持选中复制；修改输入内容后自动消失。
- 登录页布局更清晰，登录方式与主题切换更易理解。
