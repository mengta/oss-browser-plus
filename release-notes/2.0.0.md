# OSS Browser Plus 2.0.0

首个 2.x 大版本：主进程彻底去除 AngularJS 依赖并完成 OSS 服务模块化拆分，同时合入 1.21.14 之后的所有本地修复。

## 架构与内部重构

- **OSS 服务去 Angular + 拆分**：原 `node/capabilities/services/oss2.js`（2125 行）拆分为 `services/oss/{index,context,client,list,object,delete,copy,acl,multipart}.js`（均 <500 行）；删除 `angular-stub.js`、`global.angular`、`global.localStorage` 桩。
- 依赖改为 `account-context`（AsyncLocalStorage）请求级上下文；`$q/$timeout/$state/Toast` 等改为本地等价实现；`AuthInfo/localStorage/$rootScope` 全部改为 ctx。
- `dispatch` 直连 `oss/ram/sts`；`transfer` 存储改为 Map LRU4（key 不含 secret）；`ossstore` 设置读取改 `node/lib/app-settings`。
- 门禁：`verify-no-angular` 目录扫描 PASS（12 文件，白名单 0）。

## 功能修复

- **登录/凭证**：修复获取地址 `invalid url` 与 `app:probe-url failed`；修复私有链接空值导致的「endpoint 格式」错误；仅目录权限账号 ListBuckets 被拒仍可登录；预设路径指向单个文件时用 HeadObject 进入单文件模式（不依赖 ListObjects）；配置导入不再被无效剪贴板覆盖。
- **列表页**：收藏按钮预热与尾斜杠规范化；存储类型列、list/grid 视图图标、三档表面层级；上传完成后 400ms 防抖自动刷新当前目录；移除「保存为首页」。
- **删除**：删除弹窗传纯对象避免 IPC 克隆失败；同步异常落可关闭失败视图；空目录删除不再永久 pending。
- **提示与布局**：登录页左右分栏、深色对比度治理；失败提示 60s 或输入变化清除，可选中复制、点击不消失；一屏展示无滚动条。
- **传输/退出**：登出停止后台传输并清空账号级状态；升级失败识别；订阅信封退订。
